# 💬 OnboardX — AI-Powered Community Mentorship Engine (Frontend)

> **Built for the Build with Gemma: AI for Africa Hackathon**

OnboardX is an autonomous community onboarding agent designed to scale technical communities without burning out volunteer mentors. Instead of traditional, complex web dashboards, OnboardX meets users where they already spend their time—inside a familiar, friction-free WhatsApp-style chat interface.

This repository contains the lightweight, mobile-first **React + Vite** frontend that acts as the user-facing chat window, connecting seamlessly to an Express backend driven by **Gemma 4 Native Function Calling**.

---

### 💡 Key Features

- 📱 **WhatsApp-First UX:** Zero-friction simulated messaging interface built with Tailwind CSS.
- ⚡ **Real-Time State:** Instant user message rendering with smooth autoscroll and interactive typing indicators.
- 🛑 **Zero-Auth Overhead:** Instant access for new community members without login walls or complex onboarding friction.
- 🤖 **Agentic Guidance:** Displays deterministic, capacity-aware learning paths and mentor assignments generated by Gemma 4 backend tools.

---

### 🛠️ Tech Stack

- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS
- **Icons & UI:** Custom Mobile Container Architecture
- **Backend Target:** Node.js + Express + `@google/genai` (Gemma 4 SDK)
